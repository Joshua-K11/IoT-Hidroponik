# 🌱 Smart Hydroponic Monitoring System  
### Raspberry Pi + Blynk IoT

Sistem ini merupakan **IoT Smart Hydroponic Monitoring System** berbasis **Raspberry Pi** yang digunakan untuk memonitor kondisi lingkungan hidroponik serta mengontrol perangkat seperti **water pump** dan **cooling fan** secara **remote menggunakan aplikasi Blynk Cloud**.

Sistem membaca **suhu air** dan **suhu udara**, menampilkan data pada **LCD I2C**, serta mengirim data ke **Blynk dashboard** secara realtime.

---


# 🧰 Hardware Components

| No | Komponen | Fungsi |
|---|---|---|
| 1 | Raspberry Pi | Controller utama sistem |
| 2 | DS18B20 | Sensor suhu air |
| 3 | DHT11 | Sensor suhu udara |
| 4 | Relay Module | Mengontrol pompa dan kipas |
| 5 | Water Pump | Sirkulasi air hidroponik |
| 6 | Cooling Fan | Pendingin suhu |
| 7 | LCD 16x2 I2C | Menampilkan suhu |
| 8 | DC Power Supply Module Stepdown | Sumber daya|
